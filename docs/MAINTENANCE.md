# Maintenance Guide

Folia compatibility patches for the AdvancedEnchantments plugin. Works by decompiling the original JAR, applying scheduler migration patches, recompiling, and packaging as a fat JAR.

Current base: **AdvancedEnchantments 9.24.2** (upgraded from 9.23.6 — Jul 30 2026)

---

## Project Layout

```
ae/
├── build.gradle.kts       # Auto-detects JAR version, builds patched fat JAR
├── settings.gradle.kts    # rootProject.name = "advanced-enchantments-folia"
├── gradlew / gradlew.bat  # Gradle wrapper (Java 25 toolchain)
├── libs/                  # Dependencies + original AdvancedEnchantments-*.jar
├── patches/               # 27 .patch files (auto-generated, headers filled manually)
├── resources/             # Override files (plugin.yml, enchantments.yml, armorSets/, customWeapons/)
├── src-decompiled/        # Vineflower decompiler output (read-only reference)
├── src-patched/           # Decompiled + patches applied (hand-edit here for fixes)
├── tools/
│   └── scripts/
│       ├── decompile_src.sh       # Extract + decompile the JAR → src-decompiled/
│       ├── apply_patches.sh       # Copy src-decompiled → src-patched, apply all patches
│       └── generate_patches.sh    # Diff: no args = bulk regenerate, <path> = single file
└── docs/
```

## Build Commands

```bash
./gradlew clean build    # → build/libs/AdvancedEnchantments-<version>-folia-patched.jar
./gradlew deploy         # Copy JAR to Pterodactyl plugins directory
```

### Build Pipeline Steps

1. **extractOriginalJar** — Unpacks `libs/AdvancedEnchantments-*.jar` into `build/extracted/`
2. **compileJava** — Compiles only patched files from `src-patched/`
3. **jar** — 3-layer fat JAR assembly:
   - Layer 1: Original JAR classes minus patched `.class` files
   - Layer 2: Compiled patched classes override originals
   - Layer 3: `resources/` overrides (`enchantments.yml`, armor sets, weapons). `plugin.yml` gets `folia-supported: true` auto-injected during extraction.

### Version Detection

`build.gradle.kts` auto-detects the version from `libs/AdvancedEnchantments-*.jar`. Exactly one matching JAR must exist — having zero or multiple will fail with a clear error.

**Output filename:** `AdvancedEnchantments-${detectedVersion}-folia-patched.jar`

## Patch System

27 patches in `patches/`, auto-generated by diffing `src-patched/` against `src-decompiled/`.

### Patch File Format

```
Subject: [PATCH XXXX] ClassName: description

AE PATCH REASON: <why needed>
AE PATCH FIX: <what changed>
AE PATCH RISK: LOW | MEDIUM | HIGH

---
diff --git a/path/to/File.java b/path/to/File.java
--- a/path/to/File.java
+++ b/path/to/File.java
... unified diff ...
```

Patches are auto-generated **without** headers — `Subject`, `AE PATCH REASON/FIX/RISK` are filled manually after generation.

## Patch Scripts

### decompile_src.sh
```bash
bash tools/scripts/decompile_src.sh
```
- Auto-detects the JAR in `libs/`
- Auto-downloads Vineflower decompiler to `tools/vineflower.jar` (first run only)
- Extracts `net/advancedplugins/*.class` → decompiles → `src-decompiled/`
- Stripts shaded libs from decompile output
- Requires: `java`, `curl`, `jq`, `unzip`

### apply_patches.sh
```bash
bash tools/scripts/apply_patches.sh
```
- Copies `src-decompiled/` → `src-patched/` (nuclear replace)
- Applies all `patches/*.patch` via `git apply --directory=src-patched`
- Reports: OK/FAIL per patch, final summary count

### generate_patches.sh (single or bulk)

```bash
# Bulk regenerate all patches (preserves headers):
bash tools/scripts/generate_patches.sh

# Single file (print patch to stdout):
bash tools/scripts/generate_patches.sh <relative-path>
```

- **Bulk mode**: Finds all differing files, regenerates every patch from scratch (numbered 0001–NNNN). Saves old headers before wipe, restores after generation.
- **Single mode**: Diffs `src-decompiled/<path>` vs `src-patched/<path>`, outputs to stdout with `diff --git` header.
- Example single mode:
  ```bash
  bash tools/scripts/generate_patches.sh net/advancedplugins/ae/impl/utils/FoliaScheduler.java > patches/0021-FoliaScheduler.patch
  ```

## Upgrade Workflow (New Version)

```
1. Place new AdvancedEnchantments-<NEWVER>.jar into libs/
2. Remove old JAR from libs/  (only 1 allowed)
3. bash tools/scripts/decompile_src.sh
4. bash tools/scripts/apply_patches.sh
5. Fix any FAIL-ed patches manually in src-patched/
6. bash tools/scripts/generate_patches.sh
7. Check patch headers — auto-restored from old patches. For new patches (no old header), fill Subject, AE PATCH REASON/FIX/RISK manually.
8. ./gradlew clean build
9. ./gradlew deploy  (if deploying)
```
